# Story Notice

phpBB 3.3 extension. Puts a feedback reminder **after the last post on the last page** of topics in forums you pick.

It does not remove the pink bar in the board style. Turn that off in the style (or announcement) once this is live.

Live path: `ext/hoggle/storynotice`.

```bash
cd /home/u421947443/ssf-repositories
git clone https://github.com/hoggle123/phpbb-ext-storynotice.git
```

Enable in ACP after deploy. Customise → Story Notice: tick the story forums and, if you want, edit the text.
